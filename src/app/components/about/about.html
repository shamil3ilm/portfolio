Why me

Systems that run unattended, and don't wake anyone up.

I build production web systems end to end — from Laravel APIs and background-job pipelines to Next.js portals and Angular SPAs — for founders and product teams who need something that works, not something that only demos well.

I care about production safety in the way that only comes from watching your own code run at 3 am — transactions with rollbacks, audit trails treated as preconditions rather than nice-to-haves, uniform errors that don't leak server detail, and purpose-built test harnesses when the UI can't reach the surface you need to verify.

Recent work includes the Cert-Ed Academia tuition platform — a Next.js + Supabase app with 184 row-level-security policies and a real test suite — plus ambitious backend R&D on a GCC e-invoicing engine and a multi-tenant ERP. Production-safety instincts come from ongoing engineering in payments infrastructure. I choose the tool that fits the problem, not the tool I already know.
